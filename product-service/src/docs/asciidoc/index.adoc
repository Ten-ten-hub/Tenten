== 개요

상품 서비스 REST API 문서입니다.

=== 공통 요청 헤더

|===
|헤더명|필수|설명

|X-User-Id
|조건부 필수
|요청자 UUID (인증 필요 API에서 필수)

|X-User-Role
|조건부 필수
|요청자 권한 (MASTER_ADMIN, HUB_ADMIN, HUB_DELIVERY_MANAGER, COMPANY_MANAGER, COM_DELIVERY_MANAGER)
|===

=== 권한 정책

|===
|API|허용 권한

|상품 생성
|MASTER_ADMIN, HUB_ADMIN, COMPANY_MANAGER

|상품 조회
|전체 허용

|상품 수정
|MASTER_ADMIN, HUB_ADMIN, COMPANY_MANAGER

|상품 삭제
|MASTER_ADMIN, HUB_ADMIN
|===
