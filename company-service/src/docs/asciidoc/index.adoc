== 업체 서비스 개요

업체 서비스는 업체 생성, 조회, 검색, 수정, 삭제 및 업체 관리자 지정 기능을 제공합니다.

본 문서는 Spring RestDocs 기반으로 생성되며,
테스트를 통과한 API만 문서에 반영됩니다.
