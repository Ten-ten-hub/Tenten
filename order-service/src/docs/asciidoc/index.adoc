== 개요

주문 서비스 REST API 문서입니다.

=== 공통 요청 헤더

|===
|헤더명|필수|설명

|X-User-Id
|조건부 필수
|요청자 UUID (인증 필요 API에서 필수)

|X-User-Role
|조건부 필수
|요청자 권한 (MASTER_ADMIN, HUB_ADMIN, HUB_DELIVERY_MANAGER, COMPANY_MANAGER, COM_DELIVERY_MANAGER)
|===

=== 권한 정책

|===
|API|허용 권한

|주문 생성
|MASTER_ADMIN, HUB_ADMIN, HUB_DELIVERY_MANAGER, COMPANY_MANAGER

|주문 조회
|MASTER_ADMIN, HUB_ADMIN, HUB_DELIVERY_MANAGER, COMPANY_MANAGER

|주문 수정
|MASTER_ADMIN, HUB_ADMIN

|주문 취소
|MASTER_ADMIN, HUB_ADMIN

|주문 삭제
|MASTER_ADMIN, HUB_ADMIN
|===

=== 주문 상태

|===
|상태|설명

|CREATED
|주문 생성

|CONFIRMED
|주문 확인

|READY_FOR_DELIVERY
|배송 준비 완료

|IN_DELIVERY
|배송 중

|CANCELLED
|주문 취소

|COMPLETED
|주문 완료
|===
