== 배송 서비스 개요

배송 서비스는 배송 생성, 조회, 검색, 수정, 상태 변경, 취소, 삭제 기능과
업체 배송 담당자 / 허브 배송 담당자 배정 기능을 제공합니다.

외부 API와 내부 API를 분리하여 문서화하며,
Spring RestDocs 테스트를 통과한 API만 문서에 반영됩니다.
